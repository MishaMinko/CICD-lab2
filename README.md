# CICD-lab2

Лабораторна робота з предмету **CI/CD**. Продовження проєкту гри "Морський бій" (Battleship) — до існуючого коду додано набір юніт-тестів, лінтинг та налаштовано автоматичні CI/CD пайплайни (GitHub Actions і GitLab CI) для автоматичного запуску тестів і перевірки якості коду при кожному пуші.

Проєкт виконано як лабораторну роботу з предмету CI/CD — практичне завдання на впровадження неперервної інтеграції для наявного проєкту: написання юніт-тестів, налаштування лінтингу коду та автоматизацію їх запуску через CI-пайплайни (GitHub Actions, GitLab CI), які спрацьовують автоматично при кожному пуші в основну гілку.

## Стек технологій

- **Python**
- **Pygame** — рендеринг гри, обробка вводу, анімації
- **pytest** + **pytest-html** — юніт-тестування та генерація HTML-звіту
- **flake8** — лінтинг коду, перевірка стилю
- **GitHub Actions** / **GitLab CI** — автоматизація тестування та лінтингу

## Функціонал

- Розстановка кораблів гравцем на ігровому полі (з обертанням та магнітним прилипанням до сітки)
- Гра проти бота двох рівнів складності — легкий і складний
- Анімована радарна сітка та ефекти влучання
- Юніт-тести для кожного класу гри (Player, Ship, Button, Token, Bot)
- Автоматичний запуск тестів і лінтингу при кожному пуші в `main`

## Структура проєкту

```
main.py                        # головний файл: ігровий цикл, відмальовка, логіка ходів
classes/
├── player.py                    # клас гравця
├── ship.py                      # клас корабля (розміщення, обертання, малювання)
├── button.py                    # клас кнопки інтерфейсу
├── tokens.py                    # токени влучань/промахів
├── easybot.py                    # логіка бота легкого рівня
└── hardbot.py                    # логіка бота складного рівня
tests/                          # юніт-тести для кожного класу
assets/                         # зображення: кораблі, радар, фон, кнопки
docs/                           # UML-діаграми (use case, class, activity)
.github/workflows/python-ci.yml # CI-пайплайн GitHub Actions
.gitlab-ci.yml                  # CI-пайплайн GitLab CI
.flake8                         # конфігурація лінтера
pytest.ini                      # конфігурація pytest
run_tests.sh / run_lint.sh      # скрипти запуску тестів і лінтингу
```

## Запуск

Встановити залежності:

```bash
pip install -r requirements.txt
```

Запустити гру:

```bash
python main.py
```

Запустити тести з HTML-звітом:

```bash
pytest --html=pytest_report.html
```

Запустити лінтинг:

```bash
flake8 --format=html --htmldir=flake8_report
```
